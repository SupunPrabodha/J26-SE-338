# Synthetic-only boundary

This repository is a software-development foundation, not a completed research result, approved participant study, clinical product or evidence of model performance. It screens nothing about a real person.

The public intake accepts only exact strings in the shared synthetic fixture catalog; a `synthetic: true` claim alone is not sufficient. There is no free-text collection, scraping, analytics or external monitoring. Mock confidence is the constant 0.5, uncalibrated. Faithfulness, stability and counterfactual fields are null and labelled NOT_EVALUATED.

Before real text can be introduced, the owners must obtain applicable ethics and institutional approvals, approve purpose/consent/withdrawal/retention language, validate C2 anonymization and residual-PII controls, review labels and model limitations, implement institutional deployment controls, and evaluate authorized human-review procedures. Those future decisions cannot be inferred from this bootstrap.
